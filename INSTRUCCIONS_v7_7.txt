GESTIÓ PEIXATERIA — VERSIÓ 7.7

Novetats:
- Ara es poden eliminar comandes, albarans i factures des dels resultats de consulta i des de la pantalla del document.
- Abans d’eliminar, l’aplicació demana confirmació.
- Quan s’elimina un albarà de proveïdor o un document de venda que havia generat moviments, també s’eliminen els moviments d’estoc associats.
- Les compres de llotja tenen l’acció «Eliminar». En eliminar-ne una, també es reverteix el moviment d’estoc.
- Per evitar incoherències, no es pot eliminar un albarà o una compra de llotja inclosos en una factura de proveïdor. Primer cal modificar o eliminar la factura vinculada.
- No cal executar cap SQL nou a Supabase. La sincronització existent replica les eliminacions als altres dispositius.

ACTUALITZACIÓ A GITHUB PAGES:
1. Fes una còpia de seguretat JSON des de l’aplicació.
2. Descomprimeix aquest ZIP.
3. Entra a la carpeta gestio_peixateria_v7_7.
4. Puja a l’arrel del repositori GitHub tots els fitxers que hi ha dins d’aquesta carpeta, substituint els anteriors.
5. Fes Commit changes i espera que GitHub Pages publiqui els canvis.
6. Obre l’aplicació i, si apareix l’avís de nova versió, prem «Actualitzar».

Les dades es mantenen a IndexedDB i la sincronització Supabase existent no canvia. Es recomana provar primer amb una compra i un document de prova i comprovar l’estoc abans i després de l’eliminació.
